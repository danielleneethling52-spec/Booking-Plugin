# Booking-Plugin
A full-featured WordPress booking plugin designed to compete with WP Travel Pro. It allows travel and service-based businesses to manage bookings, availability, pricing, and payments directly from WordPress.

Features include:

Dynamic booking forms with multiple options

Real-time availability checks

Custom pricing rules (seasonal rates, discounts)

Payment gateway integration (PayFast, PayPal, Stripe)

Automated booking notifications via email

Admin dashboard for managing bookings and reports

Multi-language & multi-currency support

Tech Stack:
PHP, MySQL, JavaScript, HTML, CSS, WordPress APIs

Role:
Designed and developed the full plugin architecture, frontend UI/UX, backend logic, database structure, and payment integration. Optimized for scalability, performance, and SEO.
